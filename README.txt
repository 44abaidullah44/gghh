UR TRADER WEBSITE — STARTER PACKAGE

Files:
- index.html: page structure and editable content
- style.css: responsive styling and animations
- script.js: mobile menu and scroll reveal effects

How to preview:
1. Extract the ZIP.
2. Open index.html in a browser. An internet connection is needed for Google Fonts and Font Awesome icons.
3. Replace sample social URLs (href="#") with your actual profiles.
4. Replace sample YouTube links with your own video links.
5. Replace https://wa.me/ with your WhatsApp link in the community button.

Important:
- This is a working front-end starter, not a published live website.
- The market chart is decorative and does not show live prices.
- Video upload management requires a backend or CMS; this starter currently provides sample video cards/links.
- This is an original visual interpretation, not a verified pixel-perfect copy of smshahidshah.com. Compare the reference and adjust assets/sections as needed.
- Hosting/domain setup is not included.
